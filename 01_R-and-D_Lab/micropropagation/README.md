# 🧪 In Vitro Micropropagation & Temporary Immersion Systems (TIS)

This folder documents the protocol architectures for micropropagation techniques optimized for low-cost, scalable plant tissue culture operations.

## Systems Covered
* **Temporary Immersion Systems (TIS):** Operational parameters for Twin-Bottle systems and SIT (Système d'Immersion Temporaire) architectures.
* **Solid Media Culture:** Traditional nutrient agar protocols for initiation and root induction.

## Process Flow
1. **Explant Selection & Sterilization:** Surface sterilization using ethanol and hypochlorite cycles.
2. **Initiation Phase:** Solid agar inoculation for culture stabilization.
3. **Multiplication Phase:** Automated liquid immersion cycles via pneumatic TIS loops.
4. **Acclimatization:** Transition to Technosoil/biochar substrate mixtures under controlled relative humidity.
