# 🧫 Culture Media Formulations & Agar Recipes

Detailed chemical compositions and preparation steps for base MS (Murashige and Skoog) media variations, organic amendments, and gelling agents.

## Standard Formulations

| Formulation Code | Target Application | Base Medium | Sucrose (g/L) | Gelling Agent / Additives | pH |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **MS-INIT-01** | Explant Initiation | Full-strength MS | 30 | Agar 7.0 g/L | 5.8 |
| **MS-MULT-02** | TIS Liquid Multiplication | Half-strength MS | 20 | None (Liquid Culture) + Cytokinin | 5.7 |
| **MS-ROOT-01** | In Vitro Rooting | Half-strength MS | 15 | Agar 6.5 g/L + Activated Charcoal (1 g/L) | 5.8 |

## Preparation Protocol
1. Dissolve stock MS nutrients in 800 mL distilled water.
2. Add carbon source (sucrose) and specific plant growth regulators (PGRs).
3. Adjust pH to 5.7 – 5.8 using 1M KOH or 1M HCl before autoclaving.
4. Bring to final 1000 mL volume and autoclave at **121°C (15 psi) for 20 minutes**.
